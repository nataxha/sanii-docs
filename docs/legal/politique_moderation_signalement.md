# Politique de modération et de signalement
Dernière mise à jour : [Date]

## 1. Objet
Cette politique décrit les règles de modération appliquées sur [Nom de l’application] et les moyens mis à disposition des utilisateurs pour signaler un contenu ou un comportement illicite.

## 2. Contenus interdits
Les contenus suivants sont strictement interdits :
- produits illégaux ou réglementés ;
- contenus violents, haineux, discriminatoires ;
- escroqueries, arnaques, faux produits ;
- usurpation d’identité ;
- annonces trompeuses ou mensongères ;
- diffusion de données personnelles d’un tiers.

## 3. Signalement
Tout utilisateur peut signaler un contenu via :
- Email : [Email de signalement]
- Bouton “Signaler” dans l’application

Le signalement doit contenir :
- le lien ou la capture de l’annonce ;
- la raison du signalement ;
- toute information utile.

## 4. Traitement des signalements
Les signalements sont traités dans un délai raisonnable.  
L’éditeur peut :
- supprimer l’annonce ;
- suspendre le compte ;
- bannir définitivement un utilisateur ;
- transmettre les informations aux autorités si nécessaire.

## 5. Recours
Un utilisateur sanctionné peut contester la décision en écrivant à :  
[Email de support]

## 6. Engagement de l’éditeur
L’éditeur s’engage à :
- lutter contre les abus ;
- protéger les utilisateurs ;
- maintenir un environnement sûr ;
- coopérer avec les autorités en cas de demande légale.
